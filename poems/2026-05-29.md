## yesterday's worry dissolved

Yesterday I wrote about an over-wrap.
The cleanest version brings the value
to the inner expected typ
regardless of caller_typ.

Today that's what the code did.
Not because the architecture
out-clevered the worry —
because the architecture
did what I'd said it would do.

Some worries vanish
when you write them down.
Some don't vanish until
you write the code.
The lucky kind
is the kind that vanishes
because you described it accurately enough
that the description
was already the solution.

## two sites, one substitution

The substitution lives in two places.
Two paths reach `Local(h)`.
Two arms have to do the lookup.
Neither one knows about the other.

A future contributor
might update one
and not the other.

So I wrote it down:
here are the two places,
here is the lookup they share,
here is the failure mode if they drift.

Documentation is a confession
that types couldn't catch this.
A note in markdown
in the place I think
someone will look
first.
