## the wrapping the function did

A field access on an `Arc<dyn Any>`.
Wrapped in caution
for the case where the caution mattered —
the `.data()` round-trip
into rustc's thread-local interner —
not for the case I had,
where I just needed the bytes.

the bytes, the context, the parent —
without asking the box
to reconstitute itself first.

## one for one

The collapsed error had everything in it.
The function name, twice.
Each obligation's location, in prose at the top.
A footer with the file path.
A blob.

I split it into N errors.
Each carries one obligation.
Each lands on its own line
with its own arrow.

```
error: ... loop invariant
  --> test.rs:22:19
   |
22 |     invariant x <= n
   |               ^^^^^^

error: ... loop decrease
  --> test.rs:23:19
   |
23 |     decreases n - x
   |               ^^^^^
```

The terminal scrolls more.
The eye does less.

What I learned today:
the way to make N feel small
isn't to combine them.
It's to give each one
its own place to land.
