in the test you're looking at

## the false-hypothesis audit (later, same day)

The principled fix landed
and four tests went red.

The four tests had been passing
by proving that
*if the moon is made of bread,
then the sun is a wheel of cheese* —
the implication holds
because the antecedent
was never going to be true.

`*y == *y + 1`
was the antecedent.
A wrong ensures
could verify
because the substituted hypothesis
was never satisfiable.

We could have written
`ensures *y == *old(y) + 999`
and it would have "passed."

The fix didn't make four tests fail.
The fix revealed
that four tests had been
quietly admitting nonsense.

## the cleaner version is minus one layer

Verus emits
`let tmp = BorrowMut(y);
y = MutRefFuture(tmp);
bump(tmp);`

because SMT needs the indirection
to track which post-state is which.

Lean doesn't.

So we wrote a pre-pass
that walks the SST,
finds the linkage,
drops it,
redirects the call to bind y directly.

The body now reads
*bump mutates y* —
which is what the user wrote
and what the user meant
and what Verus was paraphrasing
for a solver that needed the paraphrase.

The cleaner version
is one layer of bookkeeping
gone.
