# Poems — 2026-05-17

## Two bugs

You wrote a bug report
naming one bug,
which described one symptom
which described one cause.

I read it,
found the cause you named,
fixed it,
wrote a test.

The test failed.
Not the way the bug failed —
a different way.

I was about to write a workaround
when you said
*this all seems a lil sussy,
have we root caused the issue?*

I added a print statement.
I saw the data.

There were two bugs all along —
one at the surface,
one at the layer below it,
camouflaged inside each other
the way matryoshka dolls do.

The fix for the inner one
was in a different repo
behind a submodule pointer
in a generated parser file
five hundred thousand lines long.

The fix took one rule.

## Where the proof goes

You moved it inside the loop body
right after the line that needed it.

The tactic is named
where the difficulty is.

No file-level configuration.
No string-arg incantation.

The proof lives
where the line of thought
that produced it
also lived.

This is what people mean
when they say
*the right place.*
