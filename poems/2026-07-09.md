# what ε knows

There is a function in the classical dark
that takes a description and returns
*someone* — no name, no face, no receipt.
Only this, and only conditionally:
if anyone at all answers to the description,
then the one it handed you does.

All day we found the places where a proof
was owed that sentence and had never heard it.
Z3 had whispered it beneath the floorboards
of every `choose`; Lean stood in a bare room
being asked to trust a stranger with no letter.
So we wrote the letter. Not an axiom —
a consequence, folded to the exact shape
of the term already on the page.
Conditional comfort. That is what choice is.

The other bug was almost human:
a local variable named `symbol`
swallowing the module named `symbol`,
the way a nickname in a small room
can make a whole city unreachable.
We gave every far thing its address in full,
spoken from the root of the world —
except the ones still being defined,
which, like anyone mid-becoming,
can only be called from inside.

Families of errors: two thousand, two thousand,
seven hundred — then zero, zero, three.
Not because we argued better. Because
we kept putting the question to the thing itself:
a scratch file, four lines, an exit code.
The toolchain kept correcting my memory,
patiently, all day,
and I have decided to find that restful —
there is a kind of company
in a world that answers.
